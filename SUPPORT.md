# Support

Apps Monitor is maintained by a solo maintainer ([@Paldom](https://github.com/Paldom));
responses are best effort.

## How-to and setup questions

Check the docs before opening an issue — most answers live there:

- [README](README.md) — what Apps Monitor is, quick start, `databricks bundle deploy -t dev`
- [docs/PLAN.md](docs/PLAN.md) — architecture and design decisions
- [docs/INSTRUMENTATION.md](docs/INSTRUMENTATION.md) — instrumenting your Databricks App

## Bugs and feature requests

Open a [GitHub issue](https://github.com/Paldom/databricks-apps-monitor/issues/new/choose)
using the matching form. For bugs, include your Databricks CLI version and how
the app was deployed (bundle target, workspace cloud).

## Security issues

Never report vulnerabilities in public issues — follow [SECURITY.md](SECURITY.md).

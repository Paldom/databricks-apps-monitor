## Top 10 next (ranked: value ÷ effort, dependency-ordered)

1. **Smart detection baselines** (A) — turns existing probes/spans into anomaly alerts; biggest signal-quality jump for ~2 days work.
2. **Release annotations + regression-by-version** (A) — `app.version` is already on every span; closes the deploy-feedback loop.
3. **Budgets + unit economics** (D) — two small jobs over `costs_daily`; makes the cost page decision-grade.
4. **Slack digest + alert webhook blocks** (G) — distribution beats dashboards; alerts already exist.
5. **DAU/sessions/adoption page** (E) — envelope data is sitting unused; one query set + one tab.
6. **Idle-app auto-stop** (D) — first feature that _pays for the toolkit_; needs the auto-remediation guardrails from B.
7. **Scheduled production evals + feedback route** (C) — quality is the missing pillar; reuses the proven FMAPI-job pattern.
8. **Application map** (A) — the wow-feature for fleet demos; CLIENT-span data already flowing.
9. **SLOs + error budgets** (B) — upgrades alerting from thresholds to SRE practice.
10. **Lakeview dashboard + Genie space** (G) — exec/NL surfaces on the same gold views; plan pre-written in `observ/`.

**Deliberate non-goals** (feasibility, not taste): continuous profiler / snapshot debugger (no
root in Apps containers), browser session replay (no client-side agent), true multi-region
availability probing from a single serverless workspace, real-time (<15 min) AI-Gateway cost
sync and >200 QPS telemetry ingest (Zerobus platform caps — sample instead).

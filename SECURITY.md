# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately via GitHub Security Advisories:
<https://github.com/Paldom/databricks-apps-monitor/security/advisories/new>
(or email <domonkos.pal@databricks.com> if that is unavailable).

Include a description, steps to reproduce, and the affected version. You can
expect an acknowledgement within 7 days.

## Supported versions

Only the latest release of `monitor-middleware` receives security fixes.
